Brand Rules & Agent Directives

Strict invariants governing brand implementation across the client and web.

DO
  • Always use the master vector assets/brand/mark.svg.
  • Always use semantic CSS variables (var(--accent)) in UI code.
  • Preserve the 1X clearspace perimeter on all four margins.
  • Use monochrome template strands for macOS menu bar integrations.
NEVER
  • NEVER borrow or display the Git diamond logo or Git orange (#F05133).
  • NEVER apply drop shadows, 3D embossing, or gradients to brand assets.
  • NEVER redraw or approximate the mark with procedural noodles.
  • NEVER place the mark on busy, low-contrast photographic backgrounds.
