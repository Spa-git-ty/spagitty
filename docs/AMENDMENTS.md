# Amendments — pointer

The amendments book is not maintained in this repository. It is shared across all
of this author's projects and lives at:

`~/Documents/constitution/AMENDMENTS.md`

Rules are edited there, never in a per-project copy. This file exists so that
anyone — human or agent — starting from this repository knows where the binding
rules are and reads them before working here (Amendment 11).

Amendments 1 to 20 were ratified and frozen on 2026-08-14. Their text is settled:
no later amendment may contradict or narrow them, and only the author changes
them.
